# AliExpress Oman Finder

A personal shopping tool: describe what you want in plain words and it searches
AliExpress, showing real listings with the price in OMR delivered to Oman.

This repository hosts only the tool's one-page description, used as the
registered promotion channel for the AliExpress affiliate programme.

- `index.html` — the page (GitHub Pages)
- Links to AliExpress are affiliate links; this is disclosed on the page.

Not affiliated with or operated by AliExpress.
